## التحقق

السجلات واللقطات وبصمات ملفات التطبيق في [فهرس الأدلة](evidence-guided-assessment-2026-11-03/manifest.json)، على Node 22.23.3 وnpm 11.21.1 وPostgreSQL 18.6 وChromium:

- المجموعة الكاملة: **815 ملفاً و13978 اختبار وحدة ناجحاً**. اختبارات مركزة: 91 ناجحة. جولة انحدار أولى: 113 ناجحاً و61 فاشلاً بسبب محاكي React قديم لا يوفر `useSyncExternalStore`؛ حُدثت المحاكيات ثم نجحت الـ61، ونجحت المجموعة الكاملة بعد التصحيح.
- المتصفح: **7 اختبارات ناجحة في ثلاثة ملفات** على عرضي 390 و1280 بكسل، تشمل المدخل والتقييم والتنقل. فُحصت اللقطات؛ لا أخطاء JavaScript أو تجاوز أفقي في الرحلات المفحوصة. لا حفظ لشكوى المريض في localStorage أو عنوان الصفحة.
- PostgreSQL: **12 اختباراً ناجحاً في ملفين**، بينها ثلاثة للترقية: حفظ الحقائق السابقة، تراجع كامل عند تصادم جدول غير مسجل، ورفض حالة تاريخية غير متوافقة دون إصلاح تخميني أو ترحيل جزئي.
- TypeScript والبناء ناجحان. lint للملفات المتأثرة: صفر أخطاء وسبعة تحذيرات، وليس فحص lint كامل جديداً. حارس runtime: 9301 ملفاً و371 تتبعاً؛ حارس أدوات lint: 739 تتبعاً و86 manifest. لم تُخفف حواجز التبعيات.
