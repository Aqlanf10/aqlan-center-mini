## ١. الرؤية الهندسية والسريرية (System Vision & Philosophy)

انطلاقاً من التوجيه السريري المباشر لإدارة المركز:
> «وحدة السيفالوا المفروض تكون داخل وحدة التقويم لكن الان كل شي داخل ملف المريض الموضوع عشوائي...»

تحدد هذه الوثيقة المعمارية المرجعية الشاملة لنظام تقويم الأسنان والسيفالومتري، محاكاةً لأرقى المعايير العالمية المعتمدة في البرمجيات التخصصية الكبرى مثل **Dolphin Imaging & Management**، **WebCeph**، و**Carestream OrthoTrac**.

### مبدأ الفصل الهيكلي الأنيق (Architectural Separation of Concerns)
1. **ملف المريض العام (Patient Master Record):**
   - الحاضن للبيانات الديموغرافية، التنبيهات الطبية الحيوية، كشف الحساب والمطالبات المالية، والمخطط السني العام.
2. **كابينة تقويم الأسنان التخصصية (Orthodontic Specialty Cockpit):**
   - مساحة عمل تخصصية متكاملة للطبيب على كرسي العلاج (Chairside Cockpit) تجمع السجلات التشخيصية والسيفالومترية، خطة الميكانيكا الحيوية، مسار الأسلاك والشدّات، والتثبيت دون أي تشتت أو بعثرة في التبويبات العامة.

### الركن الأول: السجلات التشخيصية الأولية والسيفالومتري (Diagnostic Records & Ceph)

تُعد دراسة السيفالومتري والصور التشخيصية حجر الزاوية في اتخاذ القرار التقويمي (قلع، توسيع، تعديل نمو، جراحة فكين).

#### أ) محطة السيفالومتري ومخطط ويب سيف (Cephalometric & WebCeph Workstation)
- **مراحل السيفالومتري الأربعة (The 4 Ceph Stages):**
  1. **T1 — قبل بدء العلاج (Pre-treatment):** التقييم الهيكلي الأولي، زوايا القواطع، وبروفايل الأنسجة الرخوة.
  2. **T2 — أثناء التقدم (Progress / Mid-treatment):** تقييم حركة الجذور وانتقالها، وفحص الاستجابة العظمية بعد فك الازدحام.
  3. **T3 — بعد انتهاء العلاج (Post-treatment / Debonding):** تقييم نتيجة العلاج واستقرار الإطباق وانسجام البروفايل فور فك الحاصرات.
  4. **T4 — المتابعة والتثبيت (Retention / Follow-up):** تقييم ثبات النتيجة بعد 6–12 شهراً ومراقبة التكيف الوظيفي.

- **المدارس التشخيصية السبع المعتمدة:**
  - **شتاينر (Steiner):** زوايا الهيكل (SNA, SNB, ANB, SND) وميل القواطع بالنسبة لـ NA و NB.
  - **تويد (Tweed):** مثلث الاستقرار التشخيصي (FMA + FMIA + IMPA = 180°).
  - **داونز (Downs):** تقييم تحدب الوجه (Convexity) وزاوية المستوى الوجهي ومحور Y.
  - **مكنمارا (McNamara):** الأطوال الفكية الحقيقية (Co-A, Co-Gn) وعمود نازيون وارتفاع الوجه السفلي LAFH.
  - **ريكتس (Ricketts):** الخط الجمالي للبروفايل (E-Line) وموضع القاطع العلوي A-Pog.
  - **بيورك وجاراباك (Bjork-Jarabak):** مضلع بيورك الثلاثي (Bjork Sum = Saddle + Articular + Gonial) ونسبة دوران الفك Jarabak Ratio.
  - **ويتس (Wits):** علاقة الفكين المسقطة عمودياً على مستوى الإطباق الوظيفي بعيداً عن انزياح قاعدة الجمجمة.

#### ب) التوثيق الفوتوغرافي للتقويم (Ortho Photographic Series)
- سلسلة الصور القياسية الثمان (8 Standard Views):
  - **٥ صور داخل الفم (Intraoral):** إطباق أمامي (Frontal)، إطباق جانبي أيمن (Right Buccal)، إطباق جانبي أيسر (Left Buccal)، القوس العلوي من الأعلى (Maxillary Occlusal)، والقوس السفلي من الأعلى (Mandibular Occlusal).
  - **٣ صور للوجه والبروفايل (Facial/Extraoral):** وجه مسترخٍ أمامي (Facial Rest)، وجه مبتسم (Facial Smile)، وبروفايل جانبي 90 درجة (Profile).
- محرك المقارنة البصرية التطورية (Before / Progress / After Comparison).

#### ج) التحليل السريري للفكين والأسنان (Clinical Malocclusion Diagnosis)
- تصنيف أنجل السني (Angle's Dental Class I, II div 1, II div 2, III).
- الصنف الهيكلي الفكي (Skeletal Pattern).
- مقدار الازدحام (Crowding) أو التباعد (Spacing) بالمليمتر.
- البروز الأفقي (Overjet) والتغطية العمودية (Overbite).
- سجل النسخ التشخيصية التاريخية (Versioned Diagnosis Trail) لتوثيق تطور خطة العلاج.

### الركن الثاني: خطة العلاج والميكانيكا الحيوية (Treatment Plan & Biomechanics)

- **مواصفات الجهاز (Appliance Specification):**
  - الجهاز الثابت المعدني (Fixed Metal Brackets).
  - الجهاز الثابت الخزفي الجمالي (Fixed Ceramic).
  - المصففات الشفافة المتتابعة (Clear Aligners).
  - الأجهزة الوظيفية وتعديل النمو (Functional Appliances: Twin Block, Herbst, Facemask).
- **مقاس الشق ونظام الحاصرات (Slot & Bracket System):**
  - شق 0.022 أو 0.018.
  - فلسفة البراكيت (Roth, MBT, Damon Low-Friction).
- **خطة الميكانيكا الحيوية والتحكم بالإرساء (Anchorage & Biomechanics):**
  - قرار القلع (Four Premolars, Upper First Only, Asymmetric, Non-Extraction).
  - التوسيع الفكي (RPE / Quad-Helix).
  - الزريعات التقويمية المؤقتة (TADs / Skeletal Anchorage).
  - رفع العضة والوسائد الخلفية (Bite Turbos / Posterior Bite Blocks).

---

### الركن الثالث: مسار الجلسات وتتابع الأسلاك (Archwire Progression & Timeline)

- **شريط الأسلاك الفوري على الكرسي (Chairside High-Contrast Wire Board):**
  - عرض فوري بارز للسلك العلوي والسلك السفلي يراه الطبيب قبل فتح فم المريض.
- **التسلسل العلمي للأسلاك (Archwire Progression Sequence):**
  1. أسلاك التسوية والمحاذاة المرنة: `012 NiTi` -> `014 NiTi` -> `016 NiTi`.
  2. أسلاك المرحلة الانتقالية: `016×022 NiTi`.
  3. أسلاك المرحلة العاملة وإغلاق المسافات: `017×025 NiTi` -> `019×025 NiTi` -> `019×025 SS` (فولاذي مستطيل للتحكم بعزم الجذور).
  4. أسلاك التفاصيل والإنهاء: `019×025 TMA`.
- **المطاطات بين الفكية (Intermaxillary Elastics):**
  - تصنيف المطاطات (صنف ثانٍ Class II، صنف ثالث Class III، عمودية Vertical، مثلثية Triangle، متصالبة Cross).
- **إغلاق الحلقة السريرية (Closing the Clinical Loop):**
  - كل شدّة يتبعها فوراً اقتراح موعد التنشيط العظمي بعد 4 أسابيع، مع إمكانية الحجز المباشر وإرسال رسالة واتساب التأكيد للمريض.

---

### الركن الرابع: التثبيت والاستبقاء وإغلاق الحالة (Retention & Stability)

- **أنواع المثبتات:**
  - مثبت هاولي الأكريليكي المتحرك (Hawley Retainer).
  - المثبت الشفاف الحراري (Essix / Vacuum Formed).
  - السلك الثابت الملصق على السطح اللساني (Bonded Lingual Wire).
- **منع الارتداد (Relapse Prevention Protocol):**
  - جدول الفحص الدوري: بعد شهر، ٣ أشهر، ٦ أشهر، وسنة.
- **قواعد الإغلاق الآمن:**
  - اشتراط تسجيل المثبت المسلم للمريض قبل إغلاق الحالة، لمنع ضياع نتيجة علاج استمر سنتين.

## ٣. التكامل البرمجي وتدفق البيانات (Technical Architecture & Data Flow)

### واجهات المكونات (Component Interfaces):

```tsx
// components/PatientCeph.tsx
export interface PatientCephProps {
  patientId: number;
  orthoCaseId?: number | null;
  currentPhase?: OrthoPhase | null;
  embedded?: boolean;
  onAnalysisCreated?: (analysisId: number) => void;
}

// lib/ortho.ts
export type CephDiagnosticStage = "pretreatment" | "during" | "posttreatment" | "followup";

export function suggestCephPhase(
  orthoPhase?: OrthoPhase | null,
  adjustmentsCount?: number,
): CephDiagnosticStage;
```

### تسلسل الاستدعاء داخل واجهة المريض (`app/patients/[id]/page.tsx`):
1. عند فتح تبويب **«العلاج»**، يتم استدعاء `PatientOrtho`.
2. داخل `PatientOrtho`، تعرض كابينة التقويم الحالية مبوبة بالأركان الأربعة:
   - تبويب **السجلات والسيفالومتري** يستدعي `PatientCeph` تلقائياً مع تمرير `orthoCaseId={case.id}` و `currentPhase={case.phase}`.
   - إذا لم تكن هناك حالة قائمة بعد، تعرض `PatientOrtho` وحدة السيفالومتري التمهيدية (T1 Pre-treatment) لدراسة الشععة قبل بدء العلاج.
3. في تبويب **«الأشعة والملفات»**، تم وضع بطاقة ربط مباشرة وموحدة تعيد توجيه الطبيب إلى كابينة التقويم بنقرة واحدة، وتمنع الازدواجية والتشتت.
4. الروابط المرجعية القديمة (`?tab=ceph`) يتم توجيهها بسلاسة إلى `treatment` حيث تعيش وحدة التقويم والسيفالومتري معاً.

## ٤. تدقيق الجودة والاتساق البرمجي (Verification & Compliance)

- **TypeScript Type Safety:** جميع الواجهات البرمجية منضبطة نوعياً 100% دون استخدام `any` غير الآمن.
- **Vitest Unit Tests:** تم إضافة اختبارات تغطي دوال ومراحل التشخيص السيفالومتري التقويمي `suggestCephPhase` وتوافق الرموز السريرية T1 إلى T4 بنجاح 100%.
- **Chairside Ergonomics:** تجربة مستخدم سريعة، منخفضة النقرات، مهيأة للاستخدام المباشر على الهاتف المحمول والحاسوب اللوحي بجوار كرسي العلاج.
