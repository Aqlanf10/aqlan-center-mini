# إيصال نشر R1 للمراجعة

الكود المختبر ثابت عند2570fee23750205a7b4042a71e68e13b91943aeb (الشجرة7f4afe3f4aff8bdc4f75966556b3ddb60162b708)، فوق556f928aca4d474bf7e0e0e59307311b267ad8e9. أضيف هذا المجلد وحده في التزام الوثائق اللاحق، ثم دُفع بتقدم عادي إلىfix/hr-operational-integrity وفق تفويض الفريق الأب. لا تفعيل للكاتب أو تسجيل migrations أو تعديلPR325.

[التقرير العربي](HANDOFF_AR.md) يشرح التداخل المثبت والإصلاح وحدوده؛ [الإيصال](RECEIPT.json) يحفظ333 نجاحًا وبصمات المصدر والاختبارات؛ [برهان حماية المصدر](protected-source-proof.json) يثبت بقاء2373 ملفًا من أساسHR السابق، بما فيها996 اختبارًا وإعدادًا، مطابقة. ملفات الإيصال والتقرير الأصلية تصف وضع ما قبل الدفع وتظل محفوظة دون إعادة كتابة؛ هذا الملف يسجل نشر الأدلة اللاحق.

السجلات النهائية: unit-final.txt وpostgres-final.txt وtypecheck-final.txt وlint-final.txt. لم تُعد الفحوص عند النشر. جميع البيانات اصطناعية من PostgreSQL18.6 محلي مستهلك؛ حاويته أزيلت. فُحصت الأدلة قبل نشرها ولا تحتوي أسرار وصول أو بيانات مرضى أو موظفين حقيقيين.

بوابات التكامل ما زالت: صلاحيات الجلسة والموظف داخل المعاملة وبعد انتظار الأقفال، اتصال واحد وترتيب أقفال موحد، request ID وintent digest وإيصال إعادة مطابق، سجل تدقيق وإسقاط ذري، ملكية دائمة للبصمات، وتسجيل الهجرات وتصنيف النسخ الاحتياطي/الاستعادة/إعادة الضبط واختبارات الاستعادة العامة. نقل الجدولين ليس تكامل نسخ احتياطي كاملًا.

نسخ مصادر الإثبات في هذا المجلد محفوظة بلاحقة `.txt` حتى تبقى أدلة نصية ولا تدخل في اكتشاف الاختبارات أو فحص أنواع التطبيق؛ محتواها وبصماتها محفوظان.
