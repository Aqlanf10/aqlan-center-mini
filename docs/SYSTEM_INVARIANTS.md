# ثوابت النظام — ما لا يصير إعدادًا أبدًا

> تُقرأ هذه الوثيقة **قبل** إضافة أي مفتاح إلى منصّة الإعدادات.
>
> القاعدة: كل قيمة تشغيلية قابلة للتهيئة، و**كل قاعدة سلامة ليست قيمة تشغيلية**.
> الفرق بينهما أن الأولى تُخطئ فتُصحَّح، والثانية تُخطئ فلا يبقى ما يُصحَّح به.

الفرض في الشيفرة: `lib/settings-definitions.ts` يحمل `systemLocked` لكل تعريف، والخادم
يرفض الكتابة على المقفل حتى للمدير — فالوثيقة نصٌّ وحارسٌ معًا لا نصٌّ وحده.

---

## المالية

| الثابت | لماذا لا يُهيَّأ |
|---|---|
| السجلّ المالي append-only | مُشغِّلات القاعدة (هجرة 0005) ترفض `UPDATE` و`DELETE`. مفتاحٌ يعطّلها يعطّل الدفتر نفسه. |
| لا تعديل صامت لحدثٍ مالي تاريخيّ | التصحيح قيدٌ معاكس صريح يبقى فيه الأصل. |
| لا حذف مباشر لحدثٍ مالي | الحذف ليس مسارًا في النظام أصلًا. |
| ذرّية المعاملة | الدفعة والفاتورة والوردية تُكتب معًا أو لا تُكتب. |
| منع الردّ المزدوج | مجموع الردود ≤ الأصل، داخل المعاملة. |
| استقلال دفاتر العملات | لكل عملة وحدتها الصغرى ورصيدها؛ الخلط يفسد كل تقرير. |
| وردية مفتوحة للقبض والصرف | بلاها لا يُعرف مَن قبض ولا متى يُطابَق. |

**العملات YER/SAR/USD قيمٌ بنيوية لا نصوصٌ حرّة.** وحداتها الصغرى مختلفة
(`MINOR_UNITS`)، وكل حساب يعتمد عليها. إضافة عملة عملُ وحدةٍ ماليّة لا تحرير حقل.

---

## الأمان

| الثابت | لماذا لا يُهيَّأ |
|---|---|
| التفويض في الخادم | إخفاء زرٍّ في الواجهة ليس تفويضًا. |
| سلامة المصادقة وقواعد كلمة المرور | — |
| قناع الأسرار | لا يُعاد سرٌّ مخزَّن أبدًا، ولا يُسجَّل. |
| التشفير | AES-256-GCM للنسخ؛ المفاتيح لا تُعرض. |
| سلامة سجل التدقيق | `audit_log` لا يُعدَّل ولا يُحذف بمُشغِّلين. |
| حدود محاولات الدخول | مفتاحٌ يرفعها يفتح التخمين. |

---

## القاعدة

مفاتيح الهوية، وتكامل الإشارات، وقيود الفرادة، وتاريخ الهجرات، وحمايات
عدم-التكرار (idempotency) — كلها بنيةٌ لا تهيئة.

---

## التدقيق

- تدقيق الأفعال الحرجة **لا يُعطَّل** بمفتاح.
- تدقيق تغيير الإعدادات **لا يُعطَّل** بمفتاح — ولا حتى بمفتاحٍ يُسمّى «وضع الصيانة».

---

## النسخ الاحتياطي

- مفاتيح التشفير لا تُعرض ولا تُصدَّر.
- **لا تُفعَّل وجهةُ نسخٍ إنتاجية تلقائيًّا ولا صامتة.** التفعيل قرارٌ بشريّ صريح
  خلف بوّابته القائمة.

---

## أعلامُ المزايا (feature flags)

العلمُ يُطفئ ميزةً اختيارية، ولا يُطفئ حارسًا. ممنوع بنيويًّا:

```
disableAudit = true
allowFinancialDelete = true
skipAuthorization = true
```

كلّ علمٍ من هذا النوع مرفوضٌ في المراجعة، ولا يمكن تسجيله في سجل التعريفات لأن
`systemLocked` يمنع الكتابة عليه من أي مسار.
