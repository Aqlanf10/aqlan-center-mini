# التذكير الآلي بواتساب للأعمال (P2-12)

رابط واتساب اليدوي (`wa.me`) يبقى كما هو: الموظفة تضغط فيفتح واتساب برسالةٍ جاهزة. وهذا
المسار **يُرسل وحده** كل مساء تذكيرًا لمواعيد **الغد**، من رقم واتساب المركز الرسمي، عبر
WhatsApp Cloud API من Meta.

## ما يلزم من المالك (مرةً واحدة)

1. **حساب Meta Business** (business.facebook.com) باسم المركز، ثم «WhatsApp Business Platform».
2. **رقم هاتف للمركز** غير مستعملٍ في تطبيق واتساب العادي (أو يُنقل منه)، ويُوثَّق برسالة/مكالمة.
3. **قالب رسالة** يُسجَّل ويُعتمد لدى Meta (فئة Utility، اللغة العربية `ar`) باسم
   `appointment_reminder` وبهذا النص (المتغيّرات بالترتيب نفسه):

   ```
   السلام عليكم {{1}}،
   نذكّركم بموعدكم يوم {{2}} الساعة {{3}} في {{4}}.
   إن كان الموعد لا يناسبكم، أخبرونا لنؤجله — مكانكم محفوظ.
   للتواصل: {{5}}
   ```

   {{1}} اسم المريض · {{2}} اليوم والتاريخ · {{3}} الساعة · {{4}} اسم المركز · {{5}} هاتف المركز.
4. **رمز دائم** (System User token) بصلاحية `whatsapp_business_messaging`، و**معرّف رقم الهاتف**
   (Phone number ID) من لوحة WhatsApp.

## التهيئة على الخادم (Railway — خطوة المالك)

| متغيّر البيئة | القيمة |
|---|---|
| `WHATSAPP_CLOUD_TOKEN` | الرمز الدائم |
| `WHATSAPP_PHONE_NUMBER_ID` | معرّف رقم الهاتف (أرقام) |
| `WHATSAPP_GRAPH_VERSION` | اختياري — الافتراضي `v21.0` |
| `INTERNAL_REMINDERS_RUN_TOKEN` | سرٌّ عشوائي طويل لنقطة الجولة |

ثم مجدولٌ يومي (Railway Cron أو أي مجدول) في المساء، مثلًا 17:00 بتوقيت اليمن:

```
POST https://<الخادم>/api/internal/reminders/run
Authorization: Bearer <INTERNAL_REMINDERS_RUN_TOKEN>
```

وأخيرًا من الإعدادات: «التذكير الآلي بواتساب للأعمال» = مفعَّل (واسم القالب ولغته إن اختلفا).

## الضمانات

- يُذكَّر **المحجوز الذي لم يُذكَّر وله رقم جوال يمني** فقط — القاعدة نفسها التي تعدّها شاشة المواعيد.
- يُعلَّم «ذُكِّر» **بعد قبول Meta** وحده، وبشرط ألّا تكون الموظفة ذكّرته يدويًّا في الأثناء.
- حدّ الإرسال أو انقطاع الشبكة ⇒ الموعد يبقى لجولةٍ لاحقة. رفض القالب أو الرمز ⇒ تتوقف الجولة
  كلها ويظهر السبب بالعربية — لا تكرار للرفض على عشرين مريضًا.
- جولةٌ واحدة في وقتٍ واحد (قفل في القاعدة)، وسقف ٣٠٠ رسالة للجولة.
- الأسرار في البيئة وحدها؛ رسائل الخطأ لا تحمل الرمز ولا ردّ Meta الخام. وسطرٌ في سجل التدقيق
  (`reminder.auto`) بالأرقام فقط: كم أُرسل، كم يُعاد، كم فشل.
