## Evidence and acceptance

`patient-premium-visual-ui.test.ts` runs the built app on the repository's disposable PostgreSQL HTTP harness, signs in using its synthetic accounts, seeds synthetic patients/plans and captures viewport/full-page PNGs at 1448, 1280 and 390. No API responses or CSS are replaced. Each scene checks viewport overflow, selected navigation, visible clinical warning and JavaScript errors. No screenshots, HAR or auth state from staging/real patients are exported.

The [final review](PATIENT_PREMIUM_REFERENCE_REVIEW.md) and [portable evidence gallery](evidence/final/README.md) record implementation, actual captures, executable journeys and remaining differences. Baseline screenshots and local build/browser logs are retained in the review bundle. A row is **not complete** merely because it compiles or has a screenshot. Final evidence must include visual inspection against its reference and an interactive journey. Old assertions requiring expanded identity and administrative forms ahead of operational work are updated to the newly approved layout; safety, input preservation and dismissal assertions remain.

Staging direct access was denied by the environment proxy. An additive network draft includes its exact hostname; it is not yet published. No staging source or database was changed. Local implementation/testing proceeds independently.
