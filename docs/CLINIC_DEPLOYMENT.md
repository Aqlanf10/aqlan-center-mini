# دليل التشغيل الفعلي والرفع الميداني — انسياب العيادة
### مركز الدكتور عقلان الكامل لطبيّة وتقويم الأسنان

هذا الدليل الموحد يوضح خطوات إعداد وتجهيز برنامج **انسياب العيادة** لبدء العمل الفعلي صباح الغد داخل العيادة.

---

## 1. التجهيز الأولي وقاعدة البيانات

### أ. متطلبات البيئة والمتغيرات (`.env`)
تأكد من ضبط المتغيرات التالية في بيئة التشغيل (سواء كانت سحابية على Railway أو خادمًا محليًا Docker/Node.js):

| المتغيّر | الوصف | مثال / القيمة |
|---|---|---|
| `DATABASE_URL` | رابط الاتصال بقاعدة بيانات PostgreSQL | `postgresql://postgres:pass@localhost:5432/aqlan_center_mini_v2` |
| `CLINIC_TIME_ZONE` | المنطقة الزمنية للعيادة | `Asia/Aden` |
| `SESSION_SECRET` | مفتاح تشفير الجلسات (32 حرفًا فأكثر) | `openssl rand -base64 48` |
| `SETUP_TOKEN` | رمز إنشاء أول حساب للمدير (**يُحذف بعد الإنشاء**) | `SuperSecretToken2026!` |

### ب. إنشاء تهيئة القاعدة المخصصة
عند التشغيل لأول مرة داخل مشروع `aqlan-center-mini` ينفذ الأمر التالي لمرة واحدة فقط لإنشاء مخطط القاعدة وتأمين البيانات:

```bash
npm run db:provision:mini
```

---

## 2. خطوات البدء الأولى للمدير والطاقم

1. **إنشاء حساب المدير**:
   - فتح الرابط `http://localhost:3000/setup` (أو رابط السيرفر المعتمد).
   - إدخال الرمز السري `SETUP_TOKEN` وتحديد اسم المستخدم وكلمة المرور للمدير.
   - **هام جدًا**: بعد إتمام الحساب، قُم بحذف `SETUP_TOKEN` من متغيرات البيئة وإعادة تشغيل الخدمة.

2. **ضبط إعدادات العيادة الحيوية (`/settings`)**:
   - إدخال اسم المركز، اسم الطبيب الرئيسي، العناوين وأرقام التواصل لتظهر في كافة التقارير والفواتير وقسائم الطباعة بشكل توحيدي.
   - ضبط **أسعار صرف الريال السعودي والدولار** مقابل الريال اليمني لتثبيت حساب المعاملات والخصومات والدفعات بالعملات المختلفة.
   - ضبط **عدد الكراسي الفعالة في العيادة** (مثلاً: 3 كراسي).

---

## 3. تشغيل شاشة الصالة والتلفزيون (`/display`)

1. قم بفتح متصفح جهاز التلفزيون في صالة الانتظار على العنوان:
   `http://[IP_OR_DOMAIN]/display`
2. اضغط على زر **«تشغيل صوت النداء»** في الزاوية مرة واحدة عند الفتح صباح كل يوم لتجاوز قيود تشغيل الصوت الآلي في المتصفحات.
3. تظهر الأسماء والنداء الصوتية بالطابور الحي، وحالة الكراسي، والإعلانات الدورية المنظمة تلقائيًا.

---

## 4. الفحوص والتحقق الدوري والنسخ الاحتياطي

- **أخذ نسخة احتياطية فورية بنقرة زر**:
  - من شاشة `/settings/export` اضغط «نزّل النسخة الكاملة الآن» للحصول على ملف SQL شامل لكل المرضى والمواعيد والفواتير والقيود.

- **التحقق من صحة واكتمال النسخ الاحتياطية**:
  ```bash
  npm run verify:backup
  ```

- **تشغيل اختبارات النظام للتأكد من السلامة 100%**:
  ```bash
  npm test
  ```
