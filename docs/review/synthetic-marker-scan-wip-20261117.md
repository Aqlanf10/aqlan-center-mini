## Contract and limits

Run only on an immutable, isolated **synthetic** copy of all trees being evaluated. The CLI accepts a path to a JSON manifest outside the trees, with absolute `roots` and synthetic `markers`; it reports fixed classifications or counts only. `MARKER_FOUND` means a supplied marker was found. `INVALID_CONTENT`, `UNSAFE_LINK`, `LIMIT_EXCEEDED`, `INVALID_INPUT`, interruption, and missing or unscanned trees mean **inconclusive**, not clean and not necessarily a leak. Limits have hard maxima. The scanner detects raw marker bytes and selected JSON escapes, inline source-map data URIs, gzip, Brotli, zlib, ordinary ZIP and tar; it rejects unsupported or malformed known formats, unsafe archive paths, escaping/dangling/cyclic links, and trailing bytes in decoded streams. It scans filenames and internal link targets as well as contents. Its link handling and bounded reads assume the synthetic trees are not being concurrently modified; it is not a race-proof sandbox.

Brotli has no fixed signature. An exploratory decode of otherwise unknown bytes can detect some renamed streams, but can also classify normal binary data as inconclusive. In a deterministic synthetic sample of 10,000 arbitrary 16-byte files, 372 were partially decodable; rejection is not evidence of a leak. The scanner does not exhaustively decode every possible encoding, encrypted/archive format, embedded PDF/image/wasm compression, JS expression, or container-layer representation. Positive tests establish sensitivity for the tested markers and representations only. An absolute path to a root is not proof that its data is synthetic: the caller must establish that independently and include every shippable stage.

No Docker image or base layer was built or scanned in this investigation. No database or patient data was accessed for these checks. The checks above do not replace the exact **73 migration** and **15 provenance source** name/hash checks, historical 0079 restore, runtime dependency/entrypoint and static-asset checks, required CI, or security review.
