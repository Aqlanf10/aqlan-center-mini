The one-draft constraint is **not durable request idempotency**: after a draft is completed or discarded, an old request could otherwise create another. The interface never automatically replays, and a current draft does not prove which request produced it. Without sessionStorage, recovery after reload is explicitly not guaranteed.

The preserved legacy wrapper still initializes through its old route and performs its existing best-effort audit after commit. **Atomic audit is proven here for canonical copy only.** The shared copy helper does not own authorization or commit; the canonical command owns both. Existing clinical facts and unavailable-image semantics are retained, without introducing a new retention or financial policy.
