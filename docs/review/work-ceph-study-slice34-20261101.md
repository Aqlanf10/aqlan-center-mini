# الشريحة 34 — قراءة دراسة سيفالومترية محفوظة

الأساس `340e3429027bfef93b9f516272f3cf171e9599fa` على WORK نفسه. الشريحة الثالثة والأخيرة من حزمة القراءات 32–34 المصرح بها. إعادة الإنتاج بالتتابع على البناء السابق أثبتت نجاح قائمة المريض ثم 401 بدل 200 لـGET دراسة واحدة للحساب canonical المخول. لا ادعاء حادثة إنتاج أو تغيير نتيجة سريرية تاريخية.

## العقد والحدود

`GET /api/ceph/[id]` يتطلب `clinical.xrays.view` ونطاق المريض الحالي. معرف الدراسة موجب وآمن عدديًا، ولا توسعات في URL. المفقود والمرفوض وخارج النطاق لهم 404 واحد. القراءة تتبع نمط الصلاحيات المركزي ولا تعود إلى جلسة legacy عند الرفض.

تضم لقطة RR READ ONLY الواحدة الهوية بعد انتظار السياج، نطاق المريض، ملكية الدراسة والمستند والحالة التقويمية المرتبطة إن وُجدت، ثم المعايرة والقياسات والمعالم والتشخيص كما سُجلت. المستند الأجنبي أو علاقة الحالة الأجنبية ترفض الرد دون تفاصيل. المستند المملوك المخفي أو غير الصوري يبقي السجل التاريخي مع علامة عدم توفر مرجعه، دون عرض الصورة أو هويتها. لا يُستخدم محرك حساب أو تشخيص أو مجموعة مرجعية حالية لاستبدال نتائج قديمة.

الإسقاط `ceph-saved-study` محدد: metadata الدراسة وملاحظتها ومعايرتها ومؤلفوها المسجلون، القيم والمعالم والتشخيص الأصلي. هذه بيانات سريرية أصلية للدراسة تحت صلاحية الصور، وليست منحة لعرض التمويل أو بيانات مريض آخر. لا معرف مستند أو حالة تقويم، ولا URL أو صورة أو storage path أو عنوان مصدر أو مالية أو خيارات تحرير. الرموز التاريخية غير المعروفة في الكتالوج الحالي تُعرض حرفيًا؛ لا إسقاط صامت لها أو تفسير سريري جديد.

قبل تحميل المحتوى تُفحص حدود الدراسة الكاملة: 256 معلمًا و256 قياسًا و2 MiB مخزنة. التجاوز يرفض صراحة دون اختصار. القيم غير المنتهية والمعايرة الجزئية/غير الصالحة ترفض، ولا يُعاد حساب قيمة بديلة. قياسات المسودة المحفوظة تبقى `saved-unapproved` مع تحذير واضح، وملخصها ليس نتيجة معتمدة. الحالة المعروضة وصف للحالة المسجلة، لا مصادقة طبية جديدة.

الواجهة مرجع عند الطلب داخل قائمة الدراسات. لا tracer أو محرر أو صورة أو PATCH/DELETE، ولا رابط إلى صفحة legacy غير المحولة. تتحقق من هويتي الدراسة والمريض ومن شكل البيانات، وتزيل السابق عند التحديث/الإخفاء/السحب؛ مهلة 8 ثوانٍ وتقاعد للردود المتأخرة. الكاتب القديم والقراء القديمة وأجسام قائمة الشريحة 33 مطابقة للأساس؛ دليل **15** جسم دالة/ملف محمي.
