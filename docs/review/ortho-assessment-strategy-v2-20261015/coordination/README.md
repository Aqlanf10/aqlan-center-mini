## الفرق الإضافي المعتمد

اعتمد الجذر صراحة فحص بيانات سجل0051/52 قبل تخطي الإصدار المطبق داخل `migrateHoldingLock`، مع إعادة التحقق داخل معاملة الكتابة. hook المعاملة وحده لا يعمل إذا تخطى CLI الإصدار بناءً على سجل قائم. كان CLI يتحقق من checksum دون الاسم أو adopted؛ فشل اختبار PostgreSQL الأول يثبت الفجوة في `postgres-registration-cli-first.txt`. الفرق المنفذ الكامل داخل `current-shared-contracts.patch.txt`، وليس نسخة بديلة لملف migrations القديم.
