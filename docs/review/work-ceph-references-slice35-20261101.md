# الشريحة 35 — المجموعات المرجعية الحالية للسيفالومتري

الأساس المحلي `52773b4ddac2cbab2e56beb555a7d1a77d15ec5b`، واستمرار على WORK نفسه بالتفويض المتواصل. يبقى CI الرأس المنشور `a7af0bde` دليلًا لذلك الرأس وحده، وليس لهذه الإضافة. اختبار التطبيق المبني قبل التنفيذ أثبت **401 بدل 200** لحساب canonical يحمل منحة الصور، بلا جلسة legacy.

العقد `GET /api/ceph-reference-sets` يتبع القدرة الموجودة `clinical.xrays.view` وخريطة التحويل التي لا تضع نطاق مريض لهذا الكتالوج. أُضيف اسم القدرة نفسه إلى قائمتي إجراءات runtime المغلقتين، دون تعديل إثبات السلطة أو منحة جديدة أو تحويل دور إلى صلاحيات. يستطيع صاحب هذه المنحة قراءة المرجع مع نطاق مرضى `none` أو `own` غير مربوط؛ الاختبار يثبت أن ذلك لا يسمح له بقراءة دراسة مريض.

لقطة RR READ ONLY واحدة تشمل الهوية بعد انتظار السياج، المنحة، حدود الكتالوج، المجموعات المفعلة وقيمها. الإسقاط محدد: المفتاح والاسم والسكان المرجعيون والعمر والجنس والإصدار والمتوسط والانحراف المعياري المحفوظان. لا مؤلف أو معرف قاعدة أو مرضى أو صور أو تخزين أو مال. لا محرك سريري أو اختيار مرجع تلقائي أو تغيير نتيجة تاريخية. الرموز القديمة والدقة الأصلية محفوظة.

الحدود التقنية قبل تحميل المحتوى: **200 مجموعة مفعلة، 256 قيمة لكل مجموعة، و2 MiB**. تجاوزها يرفض دون بتر أو قيم افتراضية. العمر غير الصحيح وmean/sd غير المنتهيين يرفضان؛ القيود القائمة لم تُعطل. المجموعات غير المفعلة لا تظهر بتوسيع URL ولا يؤثر حجمها في الرد العام للكتالوج المخول.

الواجهة مرجع للقراءة داخل قسم السيفالومتري، وتوضح أن المراجع الحالية لا تثبت المرجع المستخدم تاريخيًا. تمسح البيانات عند التحديث والإخفاء والسحب، بمهلة 8 ثوانٍ وتقاعد للردود المتأخرة. لا محرر أو طلب كتابة/صورة أو إعادة حساب. فحص لقطة الهاتف كشف انعكاسًا بصريًا محتملًا لزوج العمر في RTL؛ فُصل الحد الأدنى والأعلى بعناوين مستقلة وأعيد البناء والمتصفح واللقطة.

التحقق المحلي النهائي المركز: **112/112 PostgreSQL في 4 ملفات** (23 جديدة، و31 قائمة، و36 دراسة، و22 runtime)، و**23/23 HTTP/متصفح في 3 ملفات** (8 جديدة، و8 قائمة، و7 دراسة)، والبناء النهائي `qLre9K2-DWaLBtuhSC013`. **67/67 وحدة وحراس في 5 ملفات**؛ تشمل 22 إسقاطًا جديدًا و6 توافق handler و29 إسقاط دراسة/قائمة و10 حراس. لا تُجمع الفحوص المتداخلة مرة ثانية مع المجموعة العامة.

محاولات لا تُحسب نجاحًا: تشغيل مركز التقط نسخ الاختبارات المولدة داخل `.next/standalone` وفشل حارس الجرد هناك؛ أُعيد مع استثناء المولد `.next/**` فقط، دون تغيير حارس المصدر. تشغيل lint العام تداخل مع حذف مجلد البناء المؤقت لـpreflight فأخفق بـENOENT؛ انتهى preflight وأُعيد lint دون ذلك التداخل فنجح: 0 أخطاء و346 تحذيرًا قائمًا، ثم TypeScript ناجح. المحاولة العامة الأولى للوحدات انتهت بـ5 إخفاقات و13557 نجاحًا بسبب غياب `SESSION_SECRET` الاصطناعي من الأمر المحلي؛ رسائل الأخطاء تثبت السبب، وأُعيدت بإعداد CI نفسه دون تعديل الاختبارات فنجحت جميعها: 13562/13562 في 806 ملفات. هذه إخفاقات محلية موثقة، لا تُحوّل إلى نجاح مصدر مزعوم.
