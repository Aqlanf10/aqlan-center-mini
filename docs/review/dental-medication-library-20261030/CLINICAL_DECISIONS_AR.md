# ورقة مراجعة د. عقلان — أربعة قرارات قبل اعتماد المساعدة الرقمية

الأدوية الأولية: باراسيتامول، إيبوبروفين، أموكسيسيلين، وكلورهكسيدين. اختيار اسم المادة يضيف سطرًا يدويًا فارغ التفاصيل؛ لا يعتمد جرعة مرجعية أو منتجًا، ولا يصدر وصفة. معاينة أموكسيسيلين الحسابية تبقى اصطناعية.

| القرار المطلوب | ما يسجله الطبيب للمراجعة |
|---|---|
| 1. المنتجات وتركيزاتها ونشراتها | لكل مادة: اسم المنتج، الشركة، الشكل، القوة أو التركيز بعد التحضير بوحدات mg/mL أو النسبة المئوية، العمر المسموح، النشرة وتاريخها، أداة القياس أو قابلية تقسيم القرص. لا مساواة تلقائية بين غسول 0.2% و0.12%. |
| 2. نظم الجرعات الأولية | تحديد ملف بالغ/طفل لكل منتج؛ الحدين الأدنى والأقصى للعمر والوزن؛ هل الوحدة mg/kg/dose أم mg/kg/day؛ نطاق الجرعة والفاصل وعدد الجرعات في 24 ساعة وسقوف الجرعة واليوم؛ الجرعات عند الحاجة إن وجدت. يراجع الطبيب مساري أموكسيسيلين كل 8 أو 12 ساعة كلًا على حدة؛ لا جرعة افتراضية عليا. |
| 3. المدد ومواعيد المراجعة | لكل استطباب: المدة المقبولة، موعد إعادة التقييم، ومعيار الإيقاف أو الإحالة. مدة أموكسيسيلين الطفل تحتاج قرارًا مستقلًا؛ لا تنقل مدة البالغ أو تعليمات إيقافه تلقائيًا. |
| 4. الاستثناءات إلى التقدير اليدوي | العمر أو الوزن أو المنتج خارج الملف؛ الرضع وحديثو الولادة؛ وزن 40 kg عند حد ملف أموكسيسيلين؛ الحساسية أو نوع تفاعل غير واضح؛ القصور الكلوي/الكبدي؛ الحمل؛ الجفاف؛ نقص وزن البالغ؛ أدوية مكررة أو متداخلة؛ عدم إمكان قياس الجرعة أو تقسيم القرص؛ غياب استطباب المضاد أو الحاجة لعلاج موضعي/إحالة. |

لكل قرار: **مقبول / يحتاج تعديل / غير مستخدم بالمركز**، مع المصدر، اسم المراجع، التاريخ، والتعديل المطلوب. هذه الورقة لا تُفعّل القوالب؛ يليها تنفيذ واختبارات ومراجعة مستقلة للمحتوى المحدد.
