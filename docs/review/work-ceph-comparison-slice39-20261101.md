قبل التنفيذ رفض المساران القانونيان 401 بدل 200 (اختبارا HTTP). كشف فحص المصدر ثم الاختبار أن القارئ القديم يعيد `xrayDate` بينما مساعد الترتيب يتوقع `takenOn`، وأن معرفات PostgreSQL النصية كانت تُرتب نصيًا عند التعادل. أُثبت ذلك بثلاثة إخفاقات وحدة واختباري HTTP حقيقيين. يدعم المساعد الآن الاسمين مع إبقاء أسبقية `takenOn`، ويقارن BIGINT بدقة دون تغيير المعرف المتسلسل في الاستجابة. رياضيات المقارنة وأحكامها القديمة لم تتغير.

وثبت باختبار HTTP ثالث أن دراسة معتمدة بلا قياسات محفوظة كان يُعاد لها قياس SNA محسوب حاليًا (45 ومتوسط 82) بدل إظهار النقص. حُذف شرط `ms.length > 0` من تحديد المجموعة المعتمدة فقط؛ المعتمدة الفارغة تبقى فارغة، والمسودة تحتفظ بمسارها القديم. هذا تصحيح قراءة بلا كتابة نتيجة تاريخية. القارئ القانوني أصلًا لا يستدعي محرك الحساب ولا يختلق متوسطًا أو وحدة تاريخية.
