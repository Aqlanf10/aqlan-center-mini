# الشريحة 33 — قائمة دراسات السيفالومتري المحفوظة

الأساس المحلي `1d7524f96a27954e830fd78d00e7a2a08c30f6a0`، على WORK نفسه ضمن الحزمة المعتمدة. قبل التنفيذ أعاد GET القائمة للحساب canonical المخول 401 بدل 200، رغم نجاح قراءة ملفه. بعد التنفيذ انتهت اختبارات النطاق وHTTP والمتصفح بنجاح؛ القبول النهائي ما زال ينتظر CI للرأس النهائي ومراجعة الأب.

العقد `GET /api/patients/[id]/ceph` يتطلب `clinical.xrays.view` ونطاق المريض الحالي، دون صلاحية مستنتجة من لقب الدور أو من عرض التقويم. صُححت الخريطة القديمة من `need:[]` إلى هذه القدرة لأن المسار القديم يطبق فعلًا `canViewXrays`. لا مرشح لتوسيع النطاق أو عرض المرفوض أو الصور. المفقود وخارج النطاق لهما 404 واحد، والملف الفارغ المشروع له قائمة فارغة صريحة.

لقطة RR READ ONLY واحدة تشمل الهوية والصلاحية بعد انتظار السياج، نطاق المريض، ملكية مستند الدراسة وحالة التقويم المرتبطة إن وُجدت، والقيم المحفوظة. الربط الأجنبي يرفض الرد دون تفاصيل؛ إخفاء المستند المملوك أو تحوله إلى نوع غير صورة يبقي قيم الدراسة مع `imageState=unavailable` دون كشف المستند أو محتواه. لا يُفتح مسار الصور بهذه الشريحة.

الإسقاط قائمة محددة: معرف الدراسة والمريض، حالة مسودة/معتمدة، المرحلة، يوم الشععة وتواريخ التسجيل/الاعتماد، حالة المرجع وثلاث قيم محفوظة ANB/FMA/WITS. المسودة أولًا ثم الأحدث، ومعرف الدراسة يحسم التعادل. الحد 300 مع `hasMore` صادقة وتحذير ظاهر. المسودات لا تعرض قيمًا كملخص معتمد، ولا تُستبدل القيم المفقودة أو غير الصالحة بحساب جديد. لا تقريب يغير القيمة المحفوظة. لا note/device/diagnosis/calibration أو أسماء مصادر أو هويات صور/مسارات تخزين أو مالية أو اختيارات تحرير.
